# Checklist de cada cambio

- [ ] El usuario pidió exactamente esto (no agrego ni quito nada más).
- [ ] Respaldo hecho y anotado (archivo o borrador con fecha).
- [ ] Cambio aplicado por texto exacto o por posición.
- [ ] Sintaxis validada antes de guardar.
- [ ] Caché limpiada.
- [ ] Verificado en vivo (computador y celular).
- [ ] Scripts temporales borrados.
- [ ] Informe al usuario: qué cambió, dónde está el respaldo, qué falta.
