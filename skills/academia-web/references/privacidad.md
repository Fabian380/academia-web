# Privacidad y datos

1. **Recoge lo mínimo.** Cada dato de un formulario debe tener un motivo escrito.
2. **La política dice cuánto tiempo se guarda cada cosa,** y el sistema lo cumple con una tarea programada (ver `templates/mu-plugin-retencion.php`).
3. **Respaldos privados:** fuera de `public_html`, con fecha, y que se descarguen a un lugar seguro del dueño. Borra los respaldos viejos cuando ya no hagan falta.
4. **Zonas restringidas:** biblioteca y campus exigen inicio de sesión. Revisa que una dirección directa no se salte el control.
5. **Limpieza:** borra páginas, entradas, carpetas y scripts que no se usan. Lo que no existe no se puede filtrar.
6. **Nunca publiques:** contraseñas, claves de API, rutas del servidor, nombres de bases de datos, datos de estudiantes ni detalles de los mecanismos de seguridad.
7. **Ley aplicable:** revisa la ley de protección de datos de tu país y enlaza la política desde todos los formularios.
